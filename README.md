# 할 일 메모판

브라우저에서 여는 포스트잇 스타일 할 일 메모판이에요.
할 일은 Supabase에 저장돼서 새로고침해도 남아 있어요.
제목 왼쪽에는 돌아가는 LP가, 오른쪽에는 오늘의 노래를 틀어 주는 Y2K MP3 플레이어 **오노추**가 있어요.

## 주요 기능

- **할 일 다루기**: 추가 · 완료 체크 · 수정 · 삭제
  - 할 일 글자를 더블클릭하거나 ✏️를 누르면 고칠 수 있어요. Enter는 저장, Esc는 취소예요.
- **마감일**: 버블로 골라요. 정하지 않음 · 오늘 · 내일 · 이번 주말 · 다음 주 · 📅 날짜 고르기
  - 메모는 마감이 가까운 순서로 보여요. 마감일이 없는 메모는 맨 아래에 와요.
  - 마감이 다가오거나 지나면 마감일 표시 색이 바뀌어요.
- **작성자 이름**: '추가' 버튼 왼쪽 칸에 적어요. 안 적어도 돼요. (20자까지)
- **링크 첨부**: 음악 사이트는 🎵, 나머지는 🔗로 보여 주고 새 탭에서 열어요.
- **필터**: 전체 · 진행 중 · 완료 중에서 골라 볼 수 있고, 남은 할 일 개수도 보여 줘요.
- **한꺼번에 지우기**: 여러 개 골라서 지우거나, 완료한 메모만 모두 지울 수 있어요.
- **오류 알림**: 저장에 실패하면 제목 아래에 무엇이 안 됐는지 알려 줘요.

### 💿 돌아가는 LP

- 제목 왼쪽에서 검은 LP가 계속 돌아요.
- 양옆의 ‹ › 화살표로 가운데 색을 이전·다음 색으로 넘겨요.
- LP를 누르면 색 버튼 20가지가 떠요. 차분한 색과 버건디·에메랄드·골드 같은 고급스러운 색이 있어요.
- 고른 색은 저장하지 않아서, 새로고침하면 베이지로 돌아가요.

### 🎧 오노추 (오늘의 노래 추천)

제목 오른쪽의 Y2K MP3 플레이어예요. 민트빛 LCD 화면에 픽셀 글꼴로 보여 줘요.

- **화면**: 흘러가는 노래 제목과 만든 사람, 노래에 맞춰 바뀌는 **실시간 가사**, 진행 막대와 시간
- **버튼**: ⏮ 이전 노래 · ▶ play / ❚❚ pause · ⏭ 다음 노래 · ☰ 노래 목록
- **노래 추가**: ☰를 눌러 YouTube 링크를 붙여 넣으면 제목과 만든 사람이 자동으로 채워져요. 노래 목록은 Supabase에 저장돼요.
- 노래를 다 들으면 다음 노래로 넘어가요.

알아 두면 좋은 점:

- **YouTube 링크만** 들을 수 있어요. 멜론, 스포티파이는 재생 기능을 바깥에 열어 주지 않아요.
- 가사는 무료 가사 서비스 [LRCLIB](https://lrclib.net)에서 찾아요. 없는 노래는 "가사를 찾지 못했어요"로 나와요.
- 일부 공식 뮤직비디오는 다른 사이트에서 재생하는 걸 막아 둬요. 그럴 땐 같은 노래의 다른 영상(예: "○○ - Topic" 채널의 음원) 링크를 넣어 보세요.

## 실행 방법

**`열기.cmd`를 더블클릭하세요.** 검은 창(작은 서버)이 뜨고 브라우저에서 `http://localhost:8123`이 열려요.
노래를 듣는 동안 검은 창은 켜 두세요. 닫으면 서버가 꺼져요.

- 설치할 것은 없어요. 컴퓨터에 [Node.js](https://nodejs.org)만 있으면 돼요.
- 서버는 이 컴퓨터 안에서만 열려요. 같은 와이파이의 다른 컴퓨터는 들어올 수 없어요.
- 윈도우가 "PC 보호" 경고를 띄우면 **추가 정보 → 실행**을 누르세요.

`index.html`을 더블클릭해서 열어도 할 일 목록은 쓸 수 있어요. 하지만 YouTube가 이렇게 연 페이지에서는 재생을 막아서, 오노추로 노래를 들을 수는 없어요.

## 파일 구조

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 모든 디자인 (흰색과 베이지 사이의 차분한 색, 둥근 버블 버튼, LP, 오노추) |
| `app.js` | 모든 동작 (할 일, 정렬, 필터, Supabase 저장, LP 색, 오노추 플레이어) |
| `config.js` | Supabase 접속 정보 (주소와 공개용 publishable key) |
| `serve.js` | 이 컴퓨터 안에서만 도는 작은 서버. 앱 파일만 내보내요. |
| `열기.cmd` | 더블클릭하면 `serve.js`를 켜고 브라우저를 열어요. |
| `index-v1.html` | 맨 처음 만든 단순 버전. 참고용으로 보관해요. |

## 데이터 저장 (Supabase)

할 일은 `todos` 표, 오노추 노래 목록은 `songs` 표에 저장해요. 접속 정보는 `config.js`에 있어요.

**`todos` 표 (할 일)**

| 칸 | 내용 | 비워도 되나 |
|---|---|---|
| `id` | 메모 번호 (자동으로 매겨요) | 안 됨 |
| `text` | 할 일 내용 | 안 됨 |
| `due` | 마감일 | 됨 |
| `link` | 첨부 링크 (http/https만) | 됨 |
| `done` | 완료했는지 | 안 됨 |
| `color` | 메모 색 (white · ivory · cream · linen · sand) | 안 됨 |
| `author` | 작성자 이름 (20자까지) | 됨 |
| `created_at` | 만든 시각 | 안 됨 |

**`songs` 표 (오노추 노래 목록)**

| 칸 | 내용 | 비워도 되나 |
|---|---|---|
| `id` | 노래 번호 (자동으로 매겨요) | 안 됨 |
| `url` | YouTube 노래 링크 | 안 됨 |
| `title` | 노래 제목 | 안 됨 |
| `artist` | 만든 사람 | 됨 |
| `created_at` | 추가한 시각 (목록 순서) | 안 됨 |

가사는 저장하지 않고, 노래를 틀 때마다 찾아와요.

## ⚠️ 보안 안내

지금은 **로그인 없이 누구나** 할 일과 노래 목록을 읽고, 추가하고, 고치고, 지울 수 있게 열어 두었어요.
`config.js`의 공개용 열쇠만 있으면 누구든 모든 할 일과 노래를 지울 수도 있다는 뜻이에요.

혼자 쓰는 동안은 괜찮지만, **페이지를 인터넷에 공개하기 전에는** 로그인을 붙이고 권한 규칙을 좁혀 주세요.

## 만든 방법

- 빌드 도구나 프레임워크, 설치할 라이브러리 없이 순수 HTML · CSS · JavaScript로 만들었어요.
- 저장은 Supabase REST API를 `fetch`로 직접 불러요.
- 오노추는 YouTube(제목 정보와 플레이어), [LRCLIB](https://lrclib.net)(가사), [Galmuri](https://github.com/quiple/galmuri)(픽셀 글꼴)를 써요. 모두 열쇠 없이 쓸 수 있어요.
