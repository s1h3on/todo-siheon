# 시헌의 할 일 목록

브라우저에서 바로 여는 포스트잇 스타일 할 일 메모판이에요.
할 일은 Supabase에 저장돼서 새로고침해도 남아 있어요.

## 주요 기능

- **할 일 다루기**: 추가 · 완료 체크 · 수정 · 삭제
  - 할 일 글자를 더블클릭하거나 ✏️를 누르면 고칠 수 있어요. Enter는 저장, Esc는 취소예요.
- **마감일**: 버블로 골라요. 정하지 않음 · 오늘 · 내일 · 이번 주말 · 다음 주 · 📅 날짜 고르기
  - 메모는 마감이 가까운 순서로 보여요. 마감일이 없는 메모는 맨 아래에 와요.
  - 마감이 다가오거나 지나면 마감일 표시 색이 바뀌어요.
- **작성자 이름**: '추가' 버튼 왼쪽 칸에 적어요. 안 적어도 돼요. (20자까지)
- **링크 첨부**: 음악 사이트는 🎵, 나머지는 🔗로 보여 주고 새 탭에서 열어요.
- **필터**: 전체 · 진행 중 · 완료 중에서 골라 볼 수 있고, 남은 할 일 개수도 보여 줘요.
- **한꺼번에 지우기**: 여러 개 골라서 지우거나, 완료한 메모만 모두 지울 수 있어요.
- **오류 알림**: 저장에 실패하면 제목 아래에 무엇이 안 됐는지 알려 줘요.

## 실행 방법

`index.html`을 더블클릭하면 기본 브라우저에서 열려요. 설치할 것은 없어요.

## 파일 구조

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 모든 디자인 (흰색과 베이지 사이의 차분한 색, 둥근 버블 버튼) |
| `app.js` | 모든 동작 (추가, 수정, 정렬, 필터, Supabase 저장) |
| `config.js` | Supabase 접속 정보 (주소와 공개용 publishable key) |
| `index-v1.html` | 맨 처음 만든 단순 버전. 참고용으로 보관해요. |

## 데이터 저장 (Supabase)

할 일은 Supabase의 `todos` 표에 저장해요. 접속 정보는 `config.js`에 있어요.

| 칸 | 내용 | 비워도 되나 |
|---|---|---|
| `id` | 메모 번호 (자동으로 매겨요) | 안 됨 |
| `text` | 할 일 내용 | 안 됨 |
| `due` | 마감일 | 됨 |
| `link` | 첨부 링크 (http/https만) | 됨 |
| `done` | 완료했는지 | 안 됨 |
| `color` | 메모 색 (white · ivory · cream · linen · sand) | 안 됨 |
| `author` | 작성자 이름 (20자까지) | 됨 |
| `created_at` | 만든 시각 | 안 됨 |

## ⚠️ 보안 안내

지금은 **로그인 없이 누구나** 할 일을 읽고, 추가하고, 고치고, 지울 수 있게 열어 두었어요.
`config.js`의 공개용 열쇠만 있으면 누구든 모든 할 일을 지울 수도 있다는 뜻이에요.

혼자 쓰는 동안은 괜찮지만, **페이지를 인터넷에 공개하기 전에는** 로그인을 붙이고 권한 규칙을 좁혀 주세요.

## 만든 방법

- 빌드 도구나 프레임워크 없이 순수 HTML · CSS · JavaScript로 만들었어요.
- 저장은 별도 라이브러리 없이 Supabase REST API를 `fetch`로 직접 불러요.
